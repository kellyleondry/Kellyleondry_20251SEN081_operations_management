# Integrated Business operations Management system

## 1. PROBLEM STATEMENT

  Managing business operations manually can be time-consuming and may sometimes lead to errors.
  The Integrated Business Operations Management System aims to provide a centralized database solution
  using Oracle PL/SQL to simplify business data management, automate database operations,
  and improve data processing and accuracy.

## 2. PROJECT OBJECTIVES
1. To improve the accuracy and organization of business information, 
2. To simplify employee data management and retrieval
3. To automate common business data operations
4. To improve the efficiency of processing multiple employee records
5. To reduce errors when managing and updating business records
6. To provide a centralized system for managing organizational information

## 3. DATA SOURCE
  The project will use sample employee and department records created manually collected from survey
  related to daily Business operations and transactions

## 4. PLANNED TABLES
  1. Employees Table
  2. Department Table
  3. Positions Table
  4. Attendance Table
  5. Tasks Table
  6. Inventory Table
  7. Customers Table
  8. Audit_Logos Table

## 5. PLANNED PL/SQL FEATURES

  User-defined records.
  %ROWTYPE attribute.
  Associative arrays.
  Nested tables.
  VARRAY collections.
  Record collections.
  Implicit cursors using SQL%ROWCOUNT, SQL%FOUND, and SQL%NOTFOUND.
  Explicit cursors using OPEN, FETCH, and CLOSE.
  BULK COLLECT.
  FORALL.
  Stored procedures and functions.
  Exception handling.
